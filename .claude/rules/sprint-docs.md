# Sprint document rules

Follow `docs/memory/sprint-report-format.md` for every status report and work plan. In short:
- Status reports are individual: tag each item (Individual) or (Team) and state my own contribution.
- Every completed item has evidence: a commit link, an output file or a test result. Missing evidence is a bracketed blank, never invented.
- Every planned item has a measurable "done when" test and a real blocker.
- Untested work (for example Unity) is listed as written but untested, and carried into the plan.
